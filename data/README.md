# Master data authority

`master_ids.json` is derived directly from the **latest uploaded Master Bible, Appendix E**. Those are proposed stable technical IDs; display names and canon are not rewritten.

`v6_reference_catalogue.json` is retained from the previously supplied V6 authoring dataset (user's latest Master package attached seven Markdown documents, not a replacement authoring JSON). It is **only a reference mechanical catalogue**. For all weapon/armour/creature appearance descriptions, `../docs/MASTER_GAME_BIBLE_FINAL.md` §11 and the protected originality register override historical V6 source cells. Do NOT generate character or weapon assets from the old `source_cells` fields without this reconciliation. The remaining content uses the canonical master document.

Catalogue sizes checked: 16 weapons, 20 standard mods, 8 armour sets, 23 consumables, 12 Echoforms, 20 local quests, 8 NPC arcs, 5 districts, 5 hearing commands and 14 quest objects. No new named species, district, or ending has been added to the design.
