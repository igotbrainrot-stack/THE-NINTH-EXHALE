# HUD art override slot (Build 09.1)

Drop a PNG here named after a HUD slot and the game uses it instead of the
08.6 placeholder in `assets/ui/hud_086/`. Any subset works; missing slots fall
back. 9-slice margins for frames and buttons go in `hud_091_slices.json`.

Full slot list, sizes, palette and provenance rules:
`docs/handover/GPT_HUD_UI_ART_HANDOVER_091.md`.
