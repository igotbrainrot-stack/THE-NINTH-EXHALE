# 07.8 Remaining Work and Risks

1. **Godot engine not executed:** import, input focus, collision, dialog scrolling, runtime type checking, rail barrier motion and audio mixing are unverified. Do not call 07.8 a live-tested release.
2. **Manifests are authored local cohorts, not individual NPC simulations:** 24/36 seats with 10+8+8+10 named-bundle rosters are provisional interface-level abstractions and need actual individual civilian agent schedules, voluntary boarding animations and unique name records before a full release. `staged` and `boarded` are deliberately separate in the code.
3. **Public vote is an evidence-backed conditional model:** requires three of six constituencies and core petition/risk disclosure, but not a full AI assembly simulation. Add dissenting dialogue, debate and public audit of procedural fairness.
4. **True Dawn is a partial, uncertain scripted resolution:** future implementation should add the actual conventional pump/sun boundary reconfiguration, long-term monitoring and the right of later public revocation.
5. **No final cinematics:** the rail signal and shutter change, ending audio plays and the summary card opens. Animated rail departures and civic consequences need proper authored world sequences.
6. **Authored maps, not complete modular procedural world:** all five districts function at source level, but actual modular 3D reconfiguration, map collision validation and seeded enemy safety remain incomplete.
7. **Art production:** outstanding Runway sprites must be imported and examined; many 07.3/07.4 enemies and some NPCs still have interim art; walking/attack/death cycles are provisional.
8. **Systems depth:** remaining bible equipment catalogue, perk/armour progression, shop/social economies, side-quest variety and accessibility/settings need implementation.
9. **Early game pacing:** a production playtest must establish if intro combats/Quorum/assemblies are engaging and readable, not simply sequences of consoles.
10. **GitHub:** project has not been pushed in this build; branch upload from the user-authenticated git environment and an actual PR review are still required.
